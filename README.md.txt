
# Full Stack Blog Application

## About the Project
A full stack blog application that allows users to register, login, create blogs and view all published blogs.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## Features
- User Registration
- User Login
- Create Blog
- View All Blogs
- MongoDB Database Integration
- Responsive User Interface

## Backend API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/register | User Registration |
| POST | /api/login | User Login |
| POST | /api/blogs | Create Blog |
| GET | /api/blogs | View All Blogs |
| GET | /api/blogs/:id | View Single Blog |

## Project Structure
- frontend/
- backend/
- README.md
- .gitignore

## Installation
1. Clone the repository.
2. Open the backend folder.
3. Run `npm install`.
4. Configure `MONGODB_URI` in the backend `.env` file.
5. Run `npm start`.
6. Open `frontend/index.html` in a browser.
